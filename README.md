# ByCycle

ByCycle is an innovative sleep improvement application that caters specifically to the needs of people assigned female at birth.
Based on the principles of cycle syncing, ByCycle aims to provide personalized guidance, promote healthy sleeping habits, and educate users on how hormonal changes impact sleep quality.

# Installation
* **Install**
* Flutter
  Run flutter doctor -v
  Use fvm to control version or checkout to different version in the flutter repo
  important command to consider - flutter channel stable

flutter pub get
